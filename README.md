# Trilsoft viscous scroll (prototype)

The real HTML page scrolls normally underneath. A WebGL2 canvas sits on top (`pointer-events: none`) and shows a
snapshot of the page (taken with html2canvas) split into vertical strips. Each strip is a damped spring, the same
Hooke's-law step used in [wobbly-windows](https://github.com/Echooff3/wobbly-windows):
`a = -k·(pos − scrollY) − damping·vel + coupling·(neighbors)`. The strips chase the real scroll position, so
content lags, overshoots and oozes into place. Falls back to plain DOM without WebGL2 or with
`prefers-reduced-motion` (add `?force=1` to override).

Look: weathered mixed-media collage (scraped plaster, rust, lichen, ink washes, sepia/bone/near-black).
All textures in `tex/` are procedural, generated by `tools/gen_textures.py` (numpy + Pillow) — no source artwork.

No build step: `index.html`, `style.css`, `viscous.js`, vendored `html2canvas-pro.min.js` (MIT; the maintained html2canvas fork — its text baselines match the browser), `tex/*`.

## Looks
Three treatments share `viscous.js`, `html2canvas-pro.min.js` and the effect defaults; per-look shader colours come from
`<body data-fx-bg / data-fx-sepia / data-fx-vignette / data-fx-ghost-light / data-fx-ghost-dark>`.
- `/` **Decay** – weathered mixed-media collage (`tools/gen_textures.py`).
- `/xerox/` **Xerox** – photocopy punk flyer (`tools/gen_xerox.py`). Uses `lab.css` for the panel/switcher.
- `/lowrider/` **Lowrider** – candy paint, gold pinstripes, gauge numerals (`tools/gen_lowrider.py`).
All textures and SVGs are procedural (numpy + Pillow); no source artwork.
